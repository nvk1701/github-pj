\### Dynamic Regret via Cumulative Gradient Norm Because first-order methods cannot guarantee finding global minima in general non-convex objectives, dynamic regret is formulated via the cumulative squared gradient norm along the trajectory: $$\\text{Reg}(T) := \\sum\_{t=1}^T \\|\\nabla \\bar{\\ell}\_t(\\theta\_t)\\|^2$$ where: \* $\\theta\_t \\in \\mathbb{R}^p$ represents model weights at step $t$. \* $\\bar{\\ell}\_t(\\theta) := \\mathbb{E}\_{P\_t}[\\ell(\\theta, z\_{t,k})]$ is the expected population loss under distribution $P\_t$. ### Uniform Distribution Shift Metric Shift between consecutive loss landscapes is measured uniformly over parameter space: $$\\gamma\_t := \\sup\_{\\theta \\in \\mathbb{R}^p} |\\bar{\\ell}\_t(\\theta) - \\bar{\\ell}\_{t+1}(\\theta)|$$ ### Expected Regret Upper Bound (Theorem 5.1) Under $L$-smoothness of $\\bar{\\ell}\_t$, bounded gradient variance $\\sigma^2$, mini-batch size $B\_t$, and setting $a\_t := 2\\eta\_t - L\\eta\_t^2 &gt; 0$ for $\\eta\_t \\le 1/L$: $$\\mathbb{E}[\\text{Reg}(T)] \\le \\mathbb{E}\\left[ \\frac{2\\bar{\\ell}\_1(\\theta\_1)}{a\_1} + \\sum\_{t=2}^T 2\\bar{\\ell}\_t(\\theta\_t) \\left( \\frac{1}{a\_t} - \\frac{1}{a\_{t-1}} \\right)\_+ \\right] + \\mathbb{E}\\left[ \\sum\_{t=1}^T \\frac{1}{a\_t} \\left( \\frac{L\\sigma^2 \\eta\_t^2}{B\_t} + 2\\gamma\_t \\right) \\right]$$ ### Optimal Closed-Form Step Size Schedule Minimizing the step-wise upper bound sequentially over $\\eta \\in (0, 1/L]$ yields: $$\\eta\_t^\* = \\frac{B\_t}{L\\sigma^2} \\left( \\sqrt{b\_t^2 + \\frac{2\\sigma^2}{B\_t}b\_t} - b\_t \\right)$$ where: $$b\_t := L\\left(\\gamma\_t + \\bar{\\ell}\_t(\\theta\_t)\\right)$$ \* In empirical settings, $\\bar{\\ell}\_t(\\theta\_t)$ is approximated without bias by the empirical mini-batch loss $\\ell\_{B\_t}(\\theta\_t)$. \* $\\eta\_t^\*$ scales monotonically with both the distribution shift $\\gamma\_t$ and loss $\\bar{\\ell}\_t(\\theta\_t)$.
